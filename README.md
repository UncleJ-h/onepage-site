# One Page (一页) Website

This repository contains the public website for One Page.

**The application source code is not open source.**

## What's here

- `index.html` — Product landing page (Chinese)
- `index-en.html` — Product landing page (English)
- `privacy.html` / `privacy-en.html` — Privacy Policy
- `support.html` / `support-en.html` — Support & FAQ
- `terms.html` / `terms-en.html` — Terms of Service

## Links

- **Website**: https://onepage.theunclej.com/
- **App Store**: https://apps.apple.com/app/id6757466992

## Deploy

This site is designed to be hosted on GitHub Pages.

```bash
# Push to GitHub Pages; Cloudflare DNS points onepage.theunclej.com here
git add .
git commit -m "Update website"
git push origin main
```
